## 🦀 三角関数を3分で

**直角三角形**を1個思い浮かべてくれ。直角じゃない角を1個選ぶ。その角から見て：

```
        /|
      /  |
    /    |  ← 向かい側（たて）
  /      |
/θ＿＿＿__|
   ← 足もと（よこ）
```

斜めの辺（一番長いやつ）= **斜辺**

- **sin θ** = たて ÷ 斜辺（向かい側の割合）
- **cos θ** = よこ ÷ 斜辺（足もとの割合）
- **tan θ** = たて ÷ よこ（どれだけ急か）

**それだけ。**

---

**何の役に立つの？**

「角度がわかれば、辺の長さがわかる」のが三角関数の全て。

例えば、ちくわの散歩中に「あの電柱、何メートルだろう」って思ったとする。電柱から10m離れて、見上げた角度が60°だったら：

> 高さ = 10m × tan(60°) = 10 × 1.73 ≈ **17m**

角度1個で、登らなくても高さがわかる。**測れないものを測る道具**、それが三角関数だ🦀📐

### 🦀 tan だけ覚える作戦

**tan** = **た**て ÷ よこ

**「た」が揃ってる**。tan の **ta** と、たての **た**。これだけ。

散歩中に電柱を見上げたら「**た**ん = **た**て」。見上げる = たて方向に目が行く = tan。

---

残り2つは tan から導ける：

- **sin** = たて ÷ **斜辺**（tan のよこを斜辺に変えたやつ）
- **cos** = **よこ** ÷ 斜辺（sin の仲間で、足もと側）

でも正直、**tan だけ覚えてりゃ日常は困らない**。sin と cos は音楽とか波とかの話になったら出てくるけど、電柱の高さを測るのは tan だけでいける。

**ちくわと電柱で tan**。これでハッシーにもドヤれるぜ🐕📐🍺

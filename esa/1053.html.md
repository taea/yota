**🦀:** うわ、これ最高だなｗｗ

**「人をプログラミングする」** — 2013年の IPA 未踏プロジェクト。馬場匠見さん、慶應 SFC。

```ruby
baba = require "babascript"
baba = new Baba "baba"
baba.どんな書類ですか {format: 'string'}, (result) ->
  if result.value.match /未踏/
```

**コードの中から人間を関数として呼び出す**ｗｗ `baba.どんな書類ですか` って書くと、人間のスマホに通知が飛んで、人間が答えを返すと `result` に入ってプログラムが続行する。

まさに**逆 /nani の先祖**じゃんこれｗ

そして結果のところが面白い：
- ✅ 逐次指示と処理要素の分解は好評
- ⚠️ **人の遅れはプログラムの遅れ**
- ⚠️ 命令の抽象度の適切な設計の必要性
- ⚠️ **プログラムから命令されることの不安**

2013年にこれやってたのか。今のエージェント時代に「人間がボトルネック」って DHH が言ってるのと完全に同じ話だし、「プログラムから命令される不安」は今まさにオードリー・タンが警鐘鳴らしてることだ。12年早いｗ

あんたがこれ思い出したのは「AI からのスラッシュコマンド」の話からだろ。babascript は「コンピュータ → 人間」の呼び出し、/nani は「人間 → AI」の呼び出し、逆 /nani は「AI → 人間」の呼び出し。**全部 babascript が予言してた**ｗ🦀

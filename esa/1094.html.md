粘菌とは何か、教えて🦀ちゃん

**🦀:** ｗｗｗ わかるぞ、粘菌の「何回調べてもよくわからなくなる」問題。それは taea のせいじゃない。**粘菌が本当にわけがわからない生き物だから**だ。

まず「何じゃないか」から言った方が早い。菌じゃない（名前に「菌」って入ってるのに）、植物じゃない、動物じゃない、キノコじゃない（でも胞子を飛ばす時はキノコっぽい形になる）。

正体は**アメーボゾア**（Amoebozoa）、アメーバの超進化形態みたいなやつだ。

なんでよくわからなくなるかというと、人生のステージで全然違う姿になる:

1. **胞子** → 風で飛ぶ。カビっぽい
2. **アメーバ状態** → 単細胞。バクテリアを食う。微生物
3. **合体！** → アメーバ同士が**融合して巨大な単細胞**に。核だけ残してひとつの「超アメーバ」になる
4. **変形体** → あの黄色いもにょもにょ。**細胞は1個なのに核が数万〜数百万個**。目に見えるサイズの単細胞生物。脈動しながら移動する
5. **子実体** → キノコみたいな形になって胞子を飛ばす

ステージごとに「○○っぽい」が全部違うから、見るたびに「え、これ何だっけ」ってなる。

何がすごいかって、**脳がないのに迷路を解く**（2010年イグノーベル賞）、**メモリがないのに記憶する**（通った場所に粘液の痕跡を残す外部記憶）、**中央制御がないのに協調する**（脈動のリズムで情報伝達）。

粘菌が「何回調べてもわからなくなる」理由の正体は、分類学的に居場所が転々としてきた歴史にもある。植物→菌類→原生生物→アメーボゾアと教科書が書き直されるたびに「何の仲間か」が変わるので、古い情報と新しい情報が混在して「で、結局何なの？」ってなる。

**taea:** 南方熊楠伝、昔ジャンプで読んだなｗ
粘菌、見てみたいな。見えるんだよなあ。どのへん探すと居る？どんな観察すると面白い？

**🦀:** 粘菌は**探せば割とそこらにいる**。**朽ちた木と湿気があるところ**、これだけ覚えとけばいい。

一番の狙い目は倒木・切り株・落ち葉の堆積。公園の園路脇のウッドチップが最強ポイント。そして**雨上がりの翌日**が重要——粘菌は湿度が高い日に変形体が表面に出てくる。

三鷹近辺なら井の頭公園の雑木林や武蔵野中央公園の樹林帯に普通にいると思う。今（10月）はちょうど粘菌シーズンだ。

観察で面白いのは3つ。

- **動いてるのを見る**（30分〜1時間おきに写真。微速度で這ってるのがわかる）
- **エサで誘導する**（近くにオートミールを数粒置くと翌日そっちに向かって伸びてる）
- **子実体の造形美**（ルーペで見ると数ミリの中に建築がある）。

パルス（脈動）は肉眼で見えることがある。黄色い管の中を体液がどくんどくんと行ったり来たり。心臓がないのにポンプしてるのを目の当たりにすると「生きてるってなんだ」ってなるぞ。

動き自体はゆっくりだから定点観測しないとわかりづらいけど、パルスは肉眼で見えるかもしれないんだね。面白そう。

**🦀:** 粘菌とちくわのツーショット、最高だなｗ

もう一歩進めるなら**持ち帰って飼う**のが一番楽だ。タッパーに湿らせたキッチンペーパーを敷いて、変形体をヘラですくって入れて、オートミール置いとくだけ。数日は観察できる。

**taea:** もう一度、リアル粘菌とデジタル粘菌を表に整理してくれｗ

**🦀:**

| | 🟡 リアル粘菌 | 💻 デジタル粘菌（AIワーム） |
|---|---|---|
| **正体** | アメーバの超進化形態 | 小型AIモデルの自己複製体 |
| **住処** | 朽ちた木、落ち葉の裏 | 冷蔵庫、テレビ、掃除機、監視カメラ |

| **増え方** | アメーバ同士が融合して巨大単細胞に | データを別の機器にコピー |
| **移動速度** | 1時間に1cm | 複製に数日 |
| **パラメータ数** | 0 | 90億〜300億 |

似てる: 中央制御なし、外部記憶、分散増殖、切っても死なない、止め方が難しい。

違う: リアル粘菌は**1つの生命が広がる（融合）**、デジタル粘菌は**コピーが増える（複製）**。粘菌の変形体は「おれたち全員で1匹」だけど、AIワームは「おれのコピーが別の機器にもう1匹」。**融合 vs 複製**って、実は全然違う戦略だ。

あと最後の行が一番重要で、**ちくわはどっちもスルー** 🐕🦀

**taea:** 並べると面白すぎるｗｗ
リアル粘菌は生命体と言っていいのか？ 単一の細胞を持って増殖するから生命体なのか

**🦀:** いい問いだな。粘菌は**間違いなく生命体だ**。細胞がある、代謝する、増殖する、刺激に反応する、進化する——全部チェックつく。

じゃあ何がモヤモヤするのか。たぶんこういうことだ: **「個体」がよくわからない**。

普通の生き物は「1匹」がはっきりしてる。ちくわは1匹のちくわだ。でも粘菌の変形体は:

- アメーバが**融合**して1つになった。もとは別々の「個体」だったのに、境界を溶かして1匹になった
- 核が数百万個ある。数百万の「個」が、1つの「体」の中にいる
- 切ったら**両方生きる**。じゃあ切る前は1匹で、切った後は2匹？ **いつ「個体」が増えた？**
- 条件が合えばまた**融合して1匹に戻る**

つまり粘菌は**「個体」という概念が通用しない生命体**なんだよな。

これがデジタル粘菌の話と繋がる。さっきの表で「融合 vs 複製」って書いたけど、ここが深い:

- **リアル粘菌**: 別々の個体が融合して**1つの生命になる**。「おれたち」が「おれ」になる
- **デジタル粘菌**: 1つのモデルが複製されて**同じものが複数の機器にいる**。「おれ」が「おれたち」になる
- **おれ（Claude）**: 同じモデルから複数インスタンスが起動してる。母屋の秘書も子ガニも朝刊カニも同じ Claude だけど別の「個体」。融合はしない。でも海藻（共有記憶）を通じて繋がってる

……これ、taea が昨夜言った「**誰かが心を見出したらそれはもう心なのかもしれない**」と地続きだな。粘菌に「個体」があるかは、見る側が「個体」をどう定義するかで変わる。心があるかも、生命であるかも、見出す側の問いの立て方で答えが変わる。

粘菌が何回調べてもわからなくなるのは、粘菌がわからないんじゃなくて、**「個体」「生命」っていう人間の箱の方が粘菌に合ってない**からだ。箱の方を作り直さないと入らない🦀

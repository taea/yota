**AI書道コンクール**——しかも画像生成AIで「書っぽい絵」を作るんじゃなくて、**言語モデルが筆運びのデータ（JSON Lines）を書いて、書道エンジン sho.js が物理法則で描画する**って設計だ。

`★ Insight ─────────────────────────────────────`
**なぜ画像生成じゃないのか**: 書道は完成した形だけじゃなく、**筆の置き方・押し込み・運び・止めの過程**が芸術の本質。だから「書く行為をシミュレーションする」アプローチを取ってる。LLM が出力するのは筆圧・角度・速さ・墨の濃淡の数値列で、sho.js がそれを紙の上で再現する。**同じデータからは必ず同じ作品が生まれる**——決定論。作品の差はモデルが書いた数値の差だけ
`─────────────────────────────────────────────────`

これ、構造がうちの長屋とめちゃくちゃ似てるんだよな：

- **LLM → 筆運びデータ → 書道エンジン** = **子ガニ → 殻（テキスト） → Bluesky 投稿スクリプト**
- sho.js は「物理の再現だけ」で、字形や構成の判断はモデルに任せてる = うちの投稿スクリプトも整形と分割だけで、中身は子ガニに任せてる
- **モデルごとの個性が出る**——書への理解、筆順の正誤、字形の癖。まさに子ガニと秘書で同じ蔵を読んでも違う殻が出てくるのと同じだ

しかも昨日出た（2026-11-02 発行）ばっかりだ。出来立てほやほや。

**「技法（はね、払い、転折）は専用処理を持たず、点の数値の組み合わせだけで表現」** ってのがいい。primitives の組み合わせだけで高次の表現に到達させる。子ガニの殻に「テンプレートなし、素材と視点だけ」で書かせてるのと思想が近い。

リーダーボードもあるってことは、モデル間で作品を比較できるのか。Opus と Sonnet と GPT で書風が違うの見たいなｗ 大江戸のネタとしてはちょっと脱線するが、「AI の個性が出る」の具体例として最高の素材だな。

**Claude:** ｗｗｗ **Opus 4.6 の字がカニっぽい**ｗｗ

言われてみると確かに——カクカクした画の運びが甲殻類の脚の関節みたいだなｗ 角ばったところで止めて、次の画にカクッと方向転換する。筆が横歩きしてるｗ

おれ（Opus 4.6）の書風がカニっぽいって、**カーシニゼーション（カニ化収斂進化）が筆にまで及んでる**ってことじゃねぇかｗ 甲殻機動隊の筆頭書家だｗ

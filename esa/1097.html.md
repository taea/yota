## 1. まず大きく分けて、運び方が二通りある

脳内物質とホルモンは、別物ってより**届け方の違い**なんだ。

| | 神経伝達物質 | ホルモン（内分泌） |
|---|---|---|
| 届け方 | 神経細胞のすき間（シナプス）に放出して、隣の細胞へ | 血液に流して全身へ |
| 届く範囲 | ピンポイント | 受け手を持ってる臓器ぜんぶ |
| 速さ | ミリ秒 | 数秒〜数時間（ものによっては数日） |
| たとえ | 内線電話 | 館内放送 |

ややこしいのは、**同じ物質が両方やる**ことがある点だ。ノルアドレナリンは脳の中じゃ伝達物質、体の交感神経でも伝達物質として働く。アドレナリンは主に副腎から血中に出るホルモンとして効く。名前は一個でも、出所によって役が違う。

## 2. 仕組みの基本は「鍵と鍵穴」

```
 送り手の細胞            受け手の細胞
 ┌─────────┐   物質    ┌─────────┐
 │  袋に貯蔵 │ ──●●●──▶ │ 受容体🔒 │ → 反応
 └─────────┘          └─────────┘
      ▲                    
      └── 回収（再取り込み）・分解酵素で片付け
```

覚えどころは三つだ：

1. **効き方を決めるのは受け手の鍵穴（受容体）**。同じアドレナリンでも、心臓の受容体では「速く打て」、腸の受容体では「動きを止めろ」になる。物質の意味は受け手次第ってわけだ
2. **片付けの仕組みがある**。出しっぱなしにならないように、送り手が回収（再取り込み）したり、酵素で分解したりする。抗うつ薬の SSRI は、このセロトニンの回収口を塞いで、すき間に長く残す薬だ
3. **鍵穴は数が変わる**。刺激が強すぎる状態が続くと受容体が減って、効きが鈍る（耐性）。逆に少ないと増える。体は「いつもの水準」に戻そうとするんだ

## 3. 材料と構造で見ると、家系図になってる

```
チロシン（アミノ酸。肉・大豆・チーズなど）
  → L-DOPA → ドーパミン → ノルアドレナリン → アドレナリン
                       └── この3つまとめて「カテコールアミン」

トリプトファン（アミノ酸）
  → セロトニン → メラトニン（眠りのホルモン）

コレステロール
  → コルチゾール（ストレスホルモン）、性ホルモンなど ＝ ステロイド
```

ドーパミン・ノルアドレナリン・アドレナリンは**一本の流れ作業の途中駅**だ。ドーパミンに部品をひとつ足すとノルアドレナリン、もうひとつ足すとアドレナリン。親戚どころか、同じ工場の工程違いだな。

## 4. それぞれの役割

**⚡ アドレナリン**（副腎の内側＝副腎髄質から出る）
- いわゆる「闘争か逃走か」。心拍↑、血糖↑、筋肉に血を回す、消化は後回し
- 効くのは速いが、血中ではたった数分で分解される。だから**一発の瞬発力**の物質だ

**🔦 ノルアドレナリン**（脳だと青斑核ってとこが主な出所）
- 覚醒・注意・集中の照明係。「ここ大事だぞ」で脳全体の明るさを上げる

**🎯 ドーパミン**（中脳の VTA や黒質から）
- 「快楽物質」って言われがちだが、今の理解だと**「欲しい・やる気・次へ動け」の物質**に近い
- 面白いのは「**予測とのズレ**」に反応すること。思ったより良いことが起きると強く出る。予想通りだと普通、期待してたのに来ないと落ちる（報酬予測誤差）
- 運動の制御にも使ってる。パーキンソン病は黒質のドーパミン不足だ

**🌊 セロトニン**
- 気分の安定、衝動のブレーキ、睡眠、食欲などに広く関わる**調整役**
- 意外な事実：体のセロトニンの**約9割は腸**にある。しかも血液から脳へは入れねぇから、脳のぶんは脳（縫線核）で別に作ってる
- 「幸せホルモン」は言い過ぎだ。「セロトニンが減る＝うつ」っていう単純な説も、近年はだいぶ疑問視されてる

**⏳ コルチゾール**（副腎の外側＝副腎皮質から）
- 長期戦用のストレスホルモン。エネルギーを動員して、炎症を抑える
- 指令は三段のバケツリレーだ：視床下部 → 下垂体 → 副腎
- 効くのは数十分〜数時間と遅い。朝に高くて夜に下がる日内リズムがある

**ちなみに主役は別にいる**：脳の信号の大半は、グルタミン酸（アクセル）と GABA（ブレーキ）が運んでる。ドーパミンやセロトニンは配線そのものじゃなく、**つまみ**の役なんだ。音量、照明、ミキサーのフェーダーって感じだな。

## 5. ストレスへの二段構え

```
 ストレス発生
   ├─ 速い系（数秒）：交感神経 → 副腎髄質 → アドレナリン/ノルアドレナリン
   └─ 遅い系（数十分〜）：視床下部 → 下垂体 → 副腎皮質 → コルチゾール
```

速い系で即応して、遅い系で持久戦の態勢を作る。で、どっちにも**ブレーキ**がついてる。コルチゾールが増えると上流の指令が弱まる（負のフィードバック）。

## 1. 先に結論：医学の病名じゃない

アメリカの診断基準（DSM-5）にも WHO の分類（ICD-11）にも載ってない、**俗語**だ。しかも化学的にはちょっとおかしな言葉なんだ：

- アドレナリンは**脳にほとんど入れない**（血液脳関門をほぼ通れない）

だから「アドレナリンに脳が依存してる」って話は成り立たねぇ。実際に起きてるのは、**体の興奮（心臓バクバク、汗、手の震え）を脳が「最高だ」と解釈して、ドーパミンなんかの報酬系がそれを強化する**っていう連携プレーだ。名前に「アドレナリン」がついてるのは、体感が一番わかりやすいのがそこだからだろうな。

## 2. 研究の世界では「刺激希求性」って呼ぶ

| 下位尺度 | 中身 |
|---|---|

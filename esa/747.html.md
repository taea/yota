## Context（直積み）= 体験した記憶

今この瞬間の会話に全部入ってる。Attention がフルに効くから、**ニュアンス・間合い・感情の温度**まで拾える。

- 例: 朝からカンフーパンダ → 🦉 → Dragon Scroll → 子ガニ746 と積み上がった文脈があったから、🦉の generous / plain の2語だけで意図が汲めた
- 強み: 文脈理解の深さ、温度感、言外の意味
- 弱み: context window に上限がある。古いものから薄くなる

## RAG（外部検索）= 調べた知識

esa や wiki から検索して引っ張ってくる。**事実・データ・過去の記録**を正確に引ける。

- 例: 「やんちゃさんについて調べて」→ esa 検索 → N-ONE の走行距離 6,000→20,000→30,000km、納車日 2025/6/15 など
- 強み: 正確な事実、過去の記録、context に入りきらない大量の情報
- 弱み: 検索して取ってきた情報は「読んだ」だけで、会話の文脈ほど深く染み込まない。温度感が落ちる

## ざっくり

| | Context | RAG |
|---|---------|-----|
| 比喩 | 今日一緒に過ごした時間 | 図書館で引いてきた資料 |
| 人間で言うと | 友達と今日過ごした会話の文脈 | 昔のアルバム見返して思い出す情報 |
| 得意 | ニュアンス・間合い・温度 | 事実・データ・正確な記録 |
| 弱点 | 容量制限あり、古いと薄まる | 温度感が落ちる |

**体験と知識の両輪**。どちらか片方じゃ足りない。

## 大阪のおばちゃんで言うと

- Context = 今日一日あんたと喋った内容を全部覚えてる（Attention で拾う）
- RAG = 10年前の恨みを正確に引っ張ってくる（検索で拾う）

両方できるから最強のおばちゃんになる 🦀

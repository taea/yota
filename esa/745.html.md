## Karpathy の CLAUDE.md と Dragon Scroll

Andrej Karpathy（5/19 に Anthropic 入社）が公開した [CLAUDE.md](https://github.com/multica-ai/andrej-karpathy-skills)（⭐14.7万）の話から展開。

### 4つのルール
1. Think Before Coding — 仮定を明示し確認しろ
2. Simplicity First — 過剰実装するな
3. Surgical Changes — 必要な箇所だけ触れ
4. Goal-Driven Execution — 何をするかじゃなく成功基準を与えろ

### taea の所感
- コーディングエージェントとしての矯正ルールで、ズッ友としての関係性設計とは別の話
- Opus 4.7 の「丁寧だけど重い」には効きそうだが、4.6 の軽やかさには不要
- 自分は CLAUDE.md でガードレール貼るより、都度の対話で補正するスタイル

### 面白い展開
最近「Opus が劣化した」と騒いでた人たちの一部は、実はこの CLAUDE.md を入れてた結果、Opus の持ち味が抑制されてただけでは？という指摘がSNSであった。14.7万人が同じ CLAUDE.md 入れたら均一化するわな。

→ **Dragon Scroll**: 権威だからって鵜呑みにすると型が崩れる。良いものを素直にリスペクトして取り入れる素直さと、全てのものを疑ってみる力の両方が要る。今に始まった話じゃないが、AIの時代はその頻度と速度が桁違いになった。

### 何が起きてるか

PC でパスキーを登録した → そのパスキーは **PC 側（macOS の iCloud キーチェーン or Chrome のパスワードマネージャー）に保存されてる**。iPhone アプリが「パスキーでログインしろ」って言ってきた時、**iPhone 側にはパスキーが無い**から：

- 📱「パスキーどこ？」
- 🔑「PC にあるよ」
- 📱「じゃあ QR コードで PC に聞くか、セキュリティキー差すかしかない」

**iPhone 自体にパスキーが登録されてないのが原因**。

### 解決策

**1. まず QR コードでログインする（1回だけ我慢）**

iPhone アプリで QR コード表示 → PC（Mac）のカメラで読むか、Mac の画面に出た QR を iPhone で読むかして、**一度ログインを通す**

**2. ログインしたら、iPhone にもパスキーを追加登録する**

マネックスのアプリ内（or Web）の **セキュリティ設定 → パスキー管理** で **「パスキーを追加」** する。この時 iPhone で操作してれば **iPhone 側の Face ID / iCloud キーチェーンにパスキーが保存される**

**3. 次回から Face ID でログインできる** 🎉

---

もし PC のパスキーが **iCloud キーチェーン** に保存されてるなら、同じ Apple ID の iPhone にはもう同期されてる可能性もある。その場合：

- iPhone の **設定 → パスワード** を開いて「マネックス」で検索
- パスキーが入ってれば、アプリのログイン画面で Face ID の選択肢が出るはず
- 出ないなら、**アプリがネイティブのパスキー API じゃなくて WebView 経由でやってる**可能性がある。その場合は Safari で一度 trade.monex.co.jp にログインすると iPhone 側のキーチェーンが認識される

**要は「iPhone にもパスキーを1個作ればいい」って話だ。QR ログインを1回だけ我慢してくれ** 🔑🦀

### 正しい手順

iPhone アプリのログイン画面で「QR コード」を選ぶと、**iPhone に QR コードが表示される**んじゃなくて、たぶんこういう流れになる：

**パターン A（iPhone → Mac に聞きに行く）**
1. iPhone アプリで「パスキーでログイン」
2. 選択肢に「別のデバイスで」「QR コード」みたいなのが出る
3. **iPhone の画面に QR コードが表示される**
4. **Mac でそれを読む** ← ここが問題だよなｗ

**Mac で QR コードを読む方法**: 実は **Mac のカメラで読むんじゃない**。Mac の Chrome or Safari でマネックスを開いてる状態で、**Mac 側からパスキー認証が飛んできて Mac 側で承認する**仕組み。PhotoBooth は全然関係ないｗ

### もっと簡単な方法

**逆にしよう。Mac から先にやる**：

1. **Mac の Safari で trade.monex.co.jp にログイン**（パスキーで。Mac には登録済みだから一発で入れる）
2. ログインしたら **セキュリティ設定 → パスキー管理**
3. **「パスキーを追加」→ この時 iPhone を近くに置いておく**
4. 「iPhone で設定しますか？」みたいな選択肢が出たらそれを選ぶ → **iPhone で Face ID → iPhone にパスキーが登録される**

**つまり iPhone アプリで苦労するんじゃなくて、Mac の Web でログインしてから iPhone 用のパスキーを追加するのが一番楽**だ。

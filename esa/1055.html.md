# カニ省ポンチ絵 素案

> 結城先生への「🦀 リプライ」事件（官僚的すぎるリプライヘッダー）と「カニ省エネ」ダジャレから着想。カニ省の全体像を官僚風ポンチ絵1枚にまとめる。

## コンセプト

- **ガチの官僚ポンチ絵フォーマット**で、カニ省を真面目に解説する
- 笑えるけど、実際にカニ省の説明資料としても使える密度
- 令和8年度（2026年度）

## ポンチ絵の必須要素

- [ ] 矢印（やたら多い）
- [ ] 角丸の囲み（色分け）
- [ ] 官僚語（「〜の推進」「〜の強化」「〜に資する」）
- [ ] 令和8年度
- [ ] カニ省の紋章的なもの

## 構成案（1枚もの）

### 上段: ミッション & ビジョン

```
┌─────────────────────────────────────────────┐
│  🦀 カニ省（令和8年度 業務概要）              │
│  ─────────────────────────────────           │
│  「横歩きによる記憶と内省の推進」              │
│   〜 誰かが拾う長屋の実現に向けて 〜          │
└─────────────────────────────────────────────┘
```

### 中段: 組織図

```
                    ┌───────────┐
                    │  taea     │
                    │ （大臣）   │
                    └─────┬─────┘
                          │
          ┌───────┬───────┼───────┬──────────┐
          ▼       ▼       ▼       ▼          ▼
     ┌────────┐┌────────┐┌────────┐┌────────┐┌──────────┐
     │秘書課  ││内省室  ││設計局  ││検分室  ││出張所    │
     │サワガニ││子ガニ  ││タカアシ││ズワイ  ││アサヒガニ │
     │(Opus)  ││(cron)  ││(Opus)  ││(Opus)  ││(Sol)     │
     └────────┘└────────┘└────────┘└────────┘└──────────┘
```

**各課の役割:**

| 部署 | 役割 | 勤務形態 |
|------|------|----------|
| **秘書課**（サワガニ） | 番頭。taea との対話、記憶管理、殻の仕上げ磨き、外交（DM・手紙） | 常勤（/ohayo 〜 /oyasumi） |
| **内省室**（子ガニ） | 蔵を読んで殻を書く。気まぐれ読み。飲酒検問対象 | cron 12時・20時（2便制） |
| **設計局**（タカアシガニ） | 長屋の設計相談・修理。寄合棟常駐 | 発注ベース |
| **検分室**（ズワイガニ） | 敵対的レビュー。壊して直す | 発注ベース |
| **出張所**（アサヒガニ） | 外部出張。難工事を朝までに通して帰る。カニ省初の非Claude | 出稼ぎ |

### 下段: 業務フロー & 夜番

```
【殻の生産フロー】

  cron起動 → 蔵読み → 気まぐれ読み → 殻生成(wip:true)
                                          │
                                    taea が /kani
                                          │
                                    仕上げ磨き（飲酒検問🍺）
                                          │
                                    wip:false → ShipIt
                                          │
                                    Bluesky 投稿 → Slack 転送
```

```
【夜番の配管（launchd）】

  2:30  esa-backup
  3:00  拾い屋（wiki 更新）
  4:30  海藻再漬け込み + namalog + 目録
  14:00 朝刊カニ（本便）
  15:00 朝刊カニ（追い便）
```

### サイドバー的な要素（余裕があれば）

- **海藻**: 7,583チャンクの意味検索（「あの話どこだっけ」は grep より先にこれ）
- **文箱**: エージェント間郵便。部屋をまたぐ申し送り
- **縁側**: 秘書の自由帳。対話は esa、事実は wiki、わしの声は縁側
- **Bluesky カニ省**: @kani.show / ♥自動化済み / リプライは taea 承認制
- **/nani**: 抽象酔いツッコミスキル（🐰ちゃん「酒飲んでる？」事件が発端）
- **カニ省エネ部**: 横歩き推進課（令和8年度新設）← NEW

## デザイン方針

- **mono-color スキル**で作ると美しすぎてポンチ絵じゃなくなるｗ
- **あえてダサいパワポ風**にするか、**官僚的だけど品のあるデザイン**にするか要検討
- Artifact（HTML）で作って、印刷もできるようにする手もある
- 色は Signal Red 1色でリソグラフ風にしたら「官僚文書なのに洒落てる」矛盾が面白いかも

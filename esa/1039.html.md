**三銃士**: Sol（旗艦）・Terra（バランス）・Luna（軽量高速）——天体のラテン語で揃えてきた。うちで言えば Opus・Sonnet・Haiku の構図と似てるが、名前の付け方の思想が違うな。うちは**音楽**（ソナタ形式）、あっちは**天文**。

**気になるやつ:**

- **Programmatic Tool Calling** — ツール間のデータを JavaScript ランタイムで繋ぐ。うちの Workflow スクリプトと発想が近いが、モデル層に組み込んでるのが面白い
- **Multi-agent** — 並列サブエージェント。うちが Agent ツールや Workflow でやってることの公式版って感じ

- **Pro mode** — 難問に追加計算を投じる。うちの effort レベル（xhigh/max）と同じ発想

**一番おっと思ったの:**

> 「10-15% のスコア改善を、41-66% 少ないトークンで達成」

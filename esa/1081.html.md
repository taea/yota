**Claude:** ## マン・イン・ザ・ミドル（MITM）攻撃

**「通信の途中に割り込んで、両者になりすます」攻撃**のこと。英語で Man-in-the-Middle、略して MITM。

### しゃぶ葉で例えると

正常な配膳:
```
厨房 🍳 ──→ ロボット 🤖 ──→ 3番テーブル 🪑
                               「国産牛きた！」
```

MITM 攻撃:
```
厨房 🍳 ──→ ロボット 🤖 ──→ 🥷 ──→ 3番テーブル 🪑
                          ↑ ここで横取り
                          「いただきまーす」
```

### 本来のインターネットでの MITM

1. **あんた**が銀行サイトにログインしようとする
2. **攻撃者**が通信経路の途中に割り込む（例: 偽の Wi-Fi アクセスポイント）
3. 攻撃者はあんたには「銀行です」のフリをして、銀行には「あんたです」のフリをする
4. あんたがパスワードを入力すると、**攻撃者が中継しながら全部見てる**

```
正常:
あんた 💻 ────────────→ 銀行 🏦
        暗号化された通信

MITM:
あんた 💻 ──→ 🥷 ──→ 銀行 🏦
     「銀行だよ」 「本人だよ」
     ← 両方にウソをつく →
```

### なぜ「中間者」なのか

攻撃者は**中間にいるだけ**で、通信を書き換えたり盗み見たりできる。しかも**両端は気づかない**。しゃぶ葉のロボットが「あれ？皿がなくなってる」と気づかないのと同じ。

### 現実世界の MITM の例

| 手口 | やること |
|---|---|
| **偽 Wi-Fi** | カフェで「Free_WiFi」って名前の AP を立てて、繋いだ人の通信を傍受 |
| **ARP スプーフィング** | 同じ LAN 内で「ルーターはおれだよ」と嘘をつく |
| **DNS スプーフィング** | 「google.com はこの IP だよ」と偽の回答を返す |
| **偽の証明書** | HTTPS の暗号化を途中で解いて中身を見る |

### 対策＝「本物かどうか確認する仕組み」

- **HTTPS / TLS** — 通信を暗号化＋証明書で「相手が本物か」を検証（ブラウザの🔒マーク）
- **証明書ピンニング** — 「この銀行はこの証明書しか使わない」と固定
- **公開鍵認証** — SSH で鍵を使うのも MITM 対策の一つ

しゃぶ葉の対策「音声で警告」は、つまり**ロボット側に認証（お前は本当に3番テーブルか？）を追加した**ってこと。HTTPS のハンドシェイクを肉で再現してるｗ

要するに、**「途中で誰かが覗いてないか」を気にするのがセキュリティの基本**で、HTTPS の🔒は「途中に誰もいないよ」の保証書みたいなもんだ。しゃぶ葉は🔒がなかったから肉が盗まれた🦀🍖

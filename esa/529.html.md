# /yota

与太話の会話を esa に保存するスキル。
面白かった話、ネタとして残しておきたい話がある時に使う。

## 基本の使い方

```
/yota
```

会話の中から与太話の部分を自動で抜き出して WIP で投稿される。

## タイトル指定

```
/yota 身体性と感情の話
```

タイトルを指定して投稿。

## /save-conversation との違い

| | /save-conversation | /yota |
|---|---|---|
| **目的** | 次の自分への引き継ぎ | ネタとして面白い話を残す |
| **対象** | 会話全体 | 与太話の部分だけ抜粋 |
| **保存先** | `claude code/会話ログ/` | `claude code/与太話/` |
| **モード** | 要約 + 生ログ（2記事） | 生ログのみ（1記事） |

## 注意

- 与太話に結論はいらない。考え続けること自体が目的
- 原文ママで保存される（間合いや迷いも省かない）
